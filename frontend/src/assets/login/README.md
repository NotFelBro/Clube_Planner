# Imagens do carrossel de login e cadastro

Arquivos originais fornecidos pelo usuário, copiados da pasta Downloads:

1. `banner-01.png`: Clube Planner — Papelaria com afeto.
2. `banner-02.png`: Planeje hoje, floresça amanhã.
3. `banner-03.png`: Pequenos detalhes, grandes inspirações.

As imagens são importadas pelo Vite e mostradas inteiras, em proporção 3:2, sem recorte. Login e cadastro compartilham o mesmo carrossel, com dissolução de 700 ms e troca automática a cada três segundos. A antiga ilustração foi removida.
